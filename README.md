# HarmonyCon 2027

The coming-soon website for [harmonycon.org](https://harmonycon.org), built with Astro and hosted on Cloudflare Pages.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The static site is generated in `dist/`.

## Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js version: `22`
